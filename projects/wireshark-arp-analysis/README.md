# Wireshark ARP Spoofing Analysis

## Overview
This project focuses on analyzing ARP traffic and understanding ARP spoofing attacks using Wireshark.

## Tools Used
- Wireshark
- Packet Capture (PCAP)
- Network Protocol Analysis

## Project Description
The project involves examining captured network traffic to understand ARP communication and identify suspicious ARP behavior.

## Topics Covered
- Address Resolution Protocol (ARP)
- ARP Spoofing
- MAC Address Analysis
- Gateway Identification
- Network Traffic Inspection

## Security Concepts
- Man-in-the-Middle (MITM) Attacks
- ARP Cache Poisoning
- Network Security Analysis

## Skills Demonstrated
- Packet Analysis
- Network Troubleshooting
- Identifying Suspicious Network Activity
