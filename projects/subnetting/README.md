# IPv4 Subnetting

## Overview
This project demonstrates practical IPv4 subnetting and IP address calculations.

## Topics Covered
- IPv4 Addressing
- Subnet Masks
- CIDR Notation
- Network Addresses
- Broadcast Addresses
- Usable Host Ranges

## Project Description
This project includes practical exercises involving IPv4 subnet calculations and network planning.

## Example Exercise

**Given:** 10.1.1.200/26

- Network Address: 10.1.1.192
- Broadcast Address: 10.1.1.255
- First Usable Address: 10.1.1.193
- Last Usable Address: 10.1.1.254

## Skills Demonstrated
- IP Address Calculations
- Subnet Mask Identification
- Network Planning
